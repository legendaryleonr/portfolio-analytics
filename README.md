# Portfolio Analytics

A personal project exploring investment portfolio performance and risk using Python and React.

## About

I'm a Computer Science and Statistics student at the University of Toronto. I started this project to apply what I'm learning in programming and statistics to a practical financial application.

The goal is to build a tool that can process investment transactions, track portfolio performance, and calculate risk metrics.

I'm also using this project to gain experience with backend development, databases, testing, and building a complete web application.

## Planned Features

- Import and validate transaction data from CSV files
- Track portfolio holdings and asset allocation
- Calculate investment returns and volatility
- Analyze maximum drawdown
- Display performance through interactive charts

## Tech Stack

- Python and FastAPI
- PostgreSQL
- React
- pytest
- Docker (planned)

## Project Structure

- `backend/app/` — Python backend
- `backend/tests/` — Automated tests
- `frontend/` — React frontend
- `docs/` — Documentation
